# John Goodman portfolio foundation

This project is a lightweight, mobile-friendly personal site built for GitHub Pages.

## Files

- `index.html` — page structure and content
- `styles.css` — layout, typography, and responsive styling
- `script.js` — small enhancement for the footer year

## Preview locally

Open `index.html` directly in a browser, or run:

```bash
python3 -m http.server 8000
```

Then visit <http://localhost:8000>.

## Deploy to GitHub Pages

Push this folder to a GitHub repository and enable GitHub Pages from the repository settings. A static site is all that is required.
